# Urdu Calligraphy Generator 🖋

A Java desktop application that renders Urdu text in calligraphic 
fonts with a customizable UI — built as a 3rd semester DSA project.

## What it does
- Takes Urdu text input and displays it in calligraphic fonts
- Lets users cycle through fonts, colors, and background themes
- Adjust text size dynamically

## Data Structures Used
- **Circular Linked List** — used to cycle through font options, 
  color themes, and backgrounds in a loop
- Additional structures for managing UI state and text rendering

## Tech Stack
`Java` · Java Swing (Pure Java UI) · DSA concepts
